# AI Usage Disclosure

AI assistance was used during development as a support and reference tool, as permitted by the challenge.

* **Tools used:** ChatGPT and Claude
* **Used for:** Understanding requirements, clarifying technical concepts, debugging, and discussing implementation approaches.
* **Support provided:** AI was used to discuss API design, validation, exception handling, project structure, and testing approaches when needed.
* **Changes and corrections:** I reviewed AI suggestions against the actual starter project and modified or rejected suggestions that did not match my implementation or the project requirements.
* **What AI got wrong:** Some suggestions did not match the actual project configuration or API behaviour. I verified these suggestions against the source code and corrected them where necessary.
* **Verification:** I tested the application using Postman, ran the automated JUnit tests, and verified the API responses, HTTP status codes, and overall application behaviour.

The project was primarily developed and implemented by me. AI was used only as a supporting tool, and the final implementation was reviewed, tested, and validated by me.
